# Main UX flows — 10 October 2026

The audit followed capture/edit → save → inspect, search/filter → read → return, import → monitor → browse/review, category correction → return, candidate review, and graph exploration. It inspected the running 744-source collection and used an isolated workspace plus controlled slow/error responses for mutation tests.

The existing appearance, globe animations, reduced-motion support and solid reading surfaces remain in use. Modal keyboard navigation now also contains focus when every control is disabled during a save.

## Graph previews and document reading

Selecting a knowledge or source node in the globe, finder, or list now opens a reading panel beside the graph. The panel includes formatted content, source context or evidence/freshness status, connections, category actions, and an action to open the complete item. Long previews are explicitly shortened. On narrow screens, the panel follows the globe. Fullscreen keeps the selection and reading panel, contains keyboard focus, and exits with Escape or its exit button. Opening a detail dialog exits fullscreen so the dialog remains visible. Browsers that reject native fullscreen use a viewport-filling fallback.

Source readers previously displayed each indexed passage as a separate large card, fragmenting short routines and lists. The default now shows the selected revision as a continuous document. Sources, library reading, knowledge detail, and graph previews share formatting for headings, lists, emphasis, links, quotes, and code. Retained HTML and Note Station JSON supply a bounded, safe presentation tree that also preserves nested lists and tables. Available retained images appear with their attachments. Citation passages remain separately accessible, while hashes and original downloads sit in a collapsed details disclosure.

This is a presentation change: stored originals, extracted text, passage IDs/offsets, citations, and evidence are unchanged. Imported executable markup and remote resources are omitted. Unsupported, malformed, encrypted, oversized, or excessively deep originals fall back to extracted text. Plain-text Markdown support covers common formatting rather than the complete Markdown specification.

## Validation

The browser suite covers the original nine workflows plus seven UX regressions: failed/delayed saves and keyboard navigation, URL restoration/global search, request debouncing and stale digests, source pagination/import follow-through, partial batch failures with refreshed versions, graph/filter recovery and transient search failures, and file-upload reuse. Note Station checks also exercise bulk notebook selection and returning from category review to the retained source. Tests use isolated data; browser checks against the desktop collection do not add or edit its notes.

Drafts remain in memory until saved. The discard/leave guards prevent accidental loss during ordinary navigation; they are not durable autosave or offline editing. Search/filter URLs do not persist pagination or the reader's exact scroll position. Source filtering matches titles, notebook/project labels, tags and URLs; full-content search remains in the library.

Three additional browser workflows cover formatted knowledge and source previews, fullscreen selection/dialog behavior and Escape, native-fullscreen fallback, continuous source structure, secondary citation/hash views, omitted executable markup, and mobile overflow. The complete browser suite now has 19 workflows. Three source-presentation tests verify retained structure, safe markup/links, and fallback limits.
